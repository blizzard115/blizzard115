## Portfolio

### Stylog

日々のコーディネートを気軽に記録・共有できるファッション投稿アプリです。

ユーザーが自分のコーディネートを投稿し、タグ・いいね・コメント・フォローを通じて、記録や交流ができるサービスとして開発しました。

**主な機能**

* ユーザー登録・ログイン機能
* 投稿機能
* いいね機能
* コメント機能
* フォロー機能
* タグ機能

**使用技術**

Ruby / Ruby on Rails / PostgreSQL / Docker / RSpec / GitHub Actions / Render / AWS S3

### StoreLog

アパレル店舗向けの情報共有アプリです。  
店舗内の連絡事項を共有し、既読・未読状況を可視化できるようにしました。

前職のアパレル店舗で感じていた、紙の連絡ノートの「誰が確認したか分からない」「確認漏れが起きる」といった課題をもとに開発しました。

**主な機能**

* 店舗ごとの投稿管理
* 既読管理
* 未読ユーザーの可視化
* 重要投稿機能
* ユーザー認証機能

**使用技術**

Ruby / Ruby on Rails / PostgreSQL / Docker / RSpec / FactoryBot / Render / Neon / Tailwind CSS

🔗 https://storelog-app.onrender.com/
